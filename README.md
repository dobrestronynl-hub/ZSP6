# ZSP6 — dwie wizualizacje redesignu strony szkoły

Nieoficjalny projekt koncepcyjny dla Zespołu Szkół Ponadpodstawowych nr 6 im. Stanisława Wyspiańskiego w Tomaszowie Mazowieckim.

## Otwórz projekty

- [Wybór wariantu](index.html)
- [Wersja oficjalna i nowoczesna](oficjalna.html)
- [Wersja kreatywna i odważna](kreatywna.html)

Oba warianty są responsywne, dostępne jako samodzielne strony HTML (CSS i JS osadzono w plikach). Oryginalne logo dostarczone przez zamawiającego jest wbudowane w projekty. Kolor bazowy identyfikacji: pomarańczowy.

## Informacje o szkole i źródła

Treść wizualizacji opracowano na podstawie https://zsp6tom.pl/ oraz podstron: [rekrutacja 2026/2027](https://zsp6tom.pl/?page_id=2537), [plastyk](https://zsp6tom.pl/?page_id=3467), [grafika i poligrafia](https://zsp6tom.pl/?page_id=3520), [fotografia i multimedia](https://zsp6tom.pl/?page_id=23259), [fryzjerstwo](https://zsp6tom.pl/?page_id=23255), [kontakt](https://zsp6tom.pl/?page_id=318).

Fotografie wyświetlane są z oficjalnej strony szkoły. Ich widoczność wymaga dostępu do internetu. Projekt nie jest oficjalną witryną placówki. Nie zawiera działających systemów uczniowskich ani formularzy rekrutacyjnych.

## GitHub Pages

Aby opublikować tę wizualizację w internecie:

1. Wejdź do **Settings → Pages** w tym repozytorium.
2. Ustaw **Build and deployment / Source: Deploy from a branch**.
3. Wskaż **main** i **/(root)**, kliknij **Save**.
4. Sprawdź status wdrożenia w **Actions**.

Docelowy adres: https://dobrestronynl-hub.github.io/ZSP6/

## Kolejny etap

Rozszerzenia o portfolio prac uczniów, rezerwacje pracowni i sprzętu, panel praktyk/Erasmus+ oraz interaktywny przewodnik rekrutacyjny pozostają do osobnego zaprojektowania. Przed produkcyjnym wdrożeniem należy przeprowadzić weryfikację aktualności treści, dostępności cyfrowej i zasad publikacji zdjęć.
